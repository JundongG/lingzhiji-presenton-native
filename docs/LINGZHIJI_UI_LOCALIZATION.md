# 灵智纪 UI 本地化与品牌改造

基线：Presenton `e158a014cc1e29da0a27fe539db08dcbcea5c69d`。修改日期：2026-10-03。

## 上游现状与改造边界

此固定版本没有完整界面国际化或 UI 语言开关。原有中文语言选项控制**生成内容语言**，不等于界面已汉化。本变更提供有界的常用链路中文界面，**不宣称全站已完整翻译**。

新增的界面语言支持 `zh-CN`（默认）和 `en`。入口位于工作台侧栏、生成/大纲页头、设置和登录/引导页。修改即时生效，并以 `lingzhiji.ui-language` 这一独立浏览器 localStorage 键保存；存储被禁用时可在当前会话切换，跨标签页变更也会同步。页面 `lang` 随界面切换更新。

以下内容不进入 UI 翻译：模型 ID、服务商配置键、API 路径、账户或凭据值、用户输入、生成的幻灯片、聊天回复、模板内容、导出数据。生成语言枚举及传给后端的值保持不变。用户仍需在“内容语言”里单独选择简体中文，才能明确要求生成中文内容。

## 已接入的常用界面

- 工作台导航、创建/删除/复制文稿等常用操作
- 生成模式选择、提示词、附件、页数、语言选择提示及高级设置
- 大纲浏览与修改、重新生成入口
- 聊天输入、历史对话、停止/发送、附件提示和常用错误
- 编辑侧栏常用工具、插入类型标签、页操作、演讲备注、快捷键
- 设置侧栏与文本/图片/联网服务商的主要标签、保存提示、隐私和退出登录
- 登录和完成引导、加载提示、404 与全局错误恢复
- 已登记的导出按钮、诊断及错误文案可通过同一翻译函数使用

`lib/ui-i18n/messages.ts` 存放人工审核的英文源文 → 中文词条。缺少词条时保留原文，不模糊匹配或翻译任意 DOM 文本。`useUiText()` 用于 React UI；`uiText()` 仅用于已知通知文案；`UiLanguageControl` 是独立的界面语言控件。

## 已知未覆盖项

- 社区筛选/设计详情、模板创作和高级模板编辑、管理员面板
- 首次引导内的部分服务商详细表单、Codex/Cloud 授权流程及说明
- 深层画布属性面板、部分插入元素分组与悬浮提示
- 快捷提示词的实际内容、模板自带说明、后端/外部服务返回的动态错误和导出警告
- 部分含页数/附件数/时间的动态句子、日期和数字格式
- 界面语言切换不会翻译已生成的内容，也不会自动重发提示词

这些区域的英文不是已完成汉化的证据。后续可以按入口补齐词条和显式调用，不能使用全局字符串替换去改模型值、配置或用户内容。

## 品牌与归属

复用维护者授权的原始“灵智纪 / ZENITHIA”透明 Logo。当前可用文件是 200×200 的 Canva 缩略图，适合小尺寸 UI，不是高清矢量母版；未重绘、未换字、未重新着色。源文件位于 `servers/nextjs/public/brand/lingzhiji-logo.png`。

主要页头、侧栏、登录/启动界面及浏览器图标使用该标识。替换了会自动覆盖页面设置的 Next 文件式浏览器图标；其中三个上游原始图标仅移存 `public/upstream-brand/` 记录出处，字节未改、不在界面使用、不表示商标授权或官方背书。仓库原有 `public/Logo.png` 与 `public/logo-with-bg.png` 等上游素材不变。页面元数据去掉了指向 `presenton.ai` 的官方 canonical、OpenGraph 宣称，避免让此分支被误认为官方部署。工作台提供“基于 Presenton · Apache-2.0”归属链接。上游云服务名称与 provider ID 保持真实名称。

主仓库 `LICENSE` 与 `NOTICE` 原样保留。Apache-2.0 第 4 条涉及提供许可证、修改说明和保留适用归属/NOTICE；第 6 条不授予上游商标许可。修改的源文件添加了修改标记。原 Logo 标识本分支，不表示 Presenton 官方认可；代码许可也不意味着转让任何商标权。没有引入、复制或解锁不明确授权的 export-core。
