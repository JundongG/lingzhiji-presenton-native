# 灵智纪 · Presenton Native

基于 Presenton 固定版本的非官方源码补丁：常用中文/EN 界面、灵智纪品牌、可编辑 PPTX 导出和有边界的模板布局修复。

保留上游的生成与 AI 对话编辑流程。本项目的增量是把受支持的 Standard 画布导出为原生文字、表格与图表，而非重新截图整页。它不会让模型自动变得准确，也不承诺任意模板、HTML 或导入 PPTX 的无损转换。

> 实测范围：固定上游版本、一个真实配置模型、五页虚构资料。请按逐项结果判断，不外推到所有模板、模型或部署。

## 功能与边界

- `Native PPTX` 独立导出：原生文本、基础形状、表格单元格、柱图/折线图/圆环图，以及图表的嵌入 XLSX 工作簿
- 导出前提交当前编辑并等待保存；保存失败或 AI 修改进行中时不下载旧稿
- 同会话、同用户归属的临时 HTTP 文件交付；不会提供无鉴权公开下载目录
- `Native Editable` 五种受控布局，以及旧稿显式布局调整：保留原文、表格和图表数据，不截断内容；不匹配或仍超量时明确拒绝
- 只读、当前已加载稿件的可见画布诊断；不读取配置、模型密钥或其他账号数据
- 中文默认、EN 可选的常用界面；语言偏好仅保存在独立浏览器本地键，不改模型 ID、内容语言或服务商配置
- SSE 空闲心跳与断线清理；不自动重试模型请求或重复执行工具

图片只支持受控来源的本地 PNG/JPEG。核心导出器只接收内存数据；资产适配层只读取已有受控静态资源、同用户资产路径，以及固定清单中的两张 Standard 原图。拒绝外部 URL、SVG、越权路径、目录穿越、符号链接、硬链接和非普通文件。图片导出后仍是图片对象，不会变成可拆解矢量。

Smart HTML、旧版演示、任意 HTML、任意导入 PPTX、复杂路径/变换/自动布局不在保证范围。已知阴影、字体和 Office 换行差异通过警告或明确错误说明，不以悄悄删掉对象或截图掩盖。

## 运行独立样稿

建议 Python 3.11 与独立虚拟环境：

```sh
python -m pip install -r requirements.txt
python scripts/export_demo.py --output-dir ./exports
```

生成初版、改稿与原生 API 回写三份标为测试数据的 PPTX。不需要账号、API key、模型或 Presenton Cloud。

## 应用到完整产品

只对以下上游快照提供应用检查：

- [Presenton](https://github.com/presenton/presenton) 0.9.11-beta
- Commit `e158a014cc1e29da0a27fe539db08dcbcea5c69d`

在全新、独立 checkout 上操作。先检查，再写入：

```sh
python scripts/apply_addon.py --presenton /path/to/presenton
python scripts/apply_addon.py --presenton /path/to/presenton --apply
```

安装器核对固定上游版本、清单和 SHA256，只复制列出的源码并应用补丁。不会安装依赖、启动服务、创建账号、填写密钥或打开公网。已改动的 checkout 请先人工审查，不以覆盖代替迁移。

完整 UI 的依赖与隔离启动见 [私有 UI 说明](docs/PRIVATE_UI_SETUP.md)。使用自己的正常模型配置；服务商是否收费、额度和隐私条款由部署者确认。不要把自托管或开源等同于模型调用免费。

本实现不依赖 `@presenton/export-core` 的私有导出实现。原有 PPTX/PDF 导出代码保留，但它们各自的依赖、服务和授权不由本补丁重新授权，完整旧导出路径未作本轮验收。

## 安全与开源卫生

- 不提交真实 `.env`、`userConfig.json`、数据库、运行日志、证书、API key 或账号会话
- 运行状态放在源码树外；服务商凭据由用户自己输入正常设置流程
- 保留认证和当前用户归属；远程宿主使用 HTTPS 与私有访问控制
- 临时原生导出只清理自己生成的临时文件，不删除原始演示资料
- 公开前运行 `python scripts/scan_public_tree.py`，扫描工作树和全部可达历史，只报告路径和匹配类别，不打印密钥值；正则不能替代人工审查
- 不将私有宿主 URL、稿件 ID 或截图中的敏感信息默认放入公开示例
